Project Detail

Churn Prediction MLOps Pipeline

A production-grade machine learning system that identifies credit card customers at risk of churning before they leave, taking the model beyond a notebook and into a served, monitored API.

Open Repository Live API Demo Back to Portfolio

What It Does

Brief Overview

I built a full 19-phase ML lifecycle covering data exploration, domain-driven feature engineering, model training, and deployment. An XGBoost classifier reaches a 0.92 F1-score and 0.99 ROC-AUC on an imbalanced dataset with a 16% churn rate, served through a FastAPI application with automated Swagger documentation and health checks.

Tools Used

Stack

  • Python
  • XGBoost / scikit-learn
  • FastAPI
  • MLflow
  • Docker

Why It Matters

Business Value

Beyond model accuracy, the pipeline tracks experiments with MLflow, locks reproducible hyperparameters and thresholds in metadata, and monitors feature drift with PSI and Jensen-Shannon divergence — so retraining triggers before performance quietly decays in production.
